# Skymarshal iOS Public Release Pack

Last updated: 2026-05-13 (reconciled)

Use this pack to prepare, submit, and launch the public iOS release from one place.

## What Is Included

- `PUBLIC_RELEASE_COPY.md` - Paste-ready App Store Connect copy fields.
- `PUBLIC_RELEASE_ASSETS.md` - Required/optional App Store visual asset specs.
- `PUBLIC_RELEASE_RUNBOOK.md` - Timeline and execution checklist for launch.
- `APP_STORE_CONNECT_PASTE_SESSION.md` - Exact App Store Connect fill order.
- `docs/SOAK_PROTOCOL.md` — large-account / real-device soak checklist (screen recording gate).
- Existing references:
  - `LISTING.md`
  - `SCREENSHOTS.md`
  - `SUBMISSION_NOTES.md`

## Canonical Hierarchy (Source of Truth)

Use this order when two docs overlap:

1. `APP_STORE_CONNECT_PASTE_SESSION.md` (execution order)
2. `PUBLIC_RELEASE_COPY.md` (metadata fields and launch copy)
3. `SUBMISSION_NOTES.md` (full reviewer note + risk audit)
4. `SCREENSHOTS.md` (storyboard and capture details)
5. `LISTING.md` (rationale and longer-form commentary)

## Fast Path (30 Minutes)

1. Fill App Store Connect metadata from `PUBLIC_RELEASE_COPY.md`.
2. Confirm icon + screenshots meet `PUBLIC_RELEASE_ASSETS.md`.
3. Execute `APP_STORE_CONNECT_PASTE_SESSION.md` top to bottom.
4. Run the pre-submit checklist in `PUBLIC_RELEASE_RUNBOOK.md`.
5. Submit build and monitor App Review.

## Launch Day Artifacts

- App Store metadata (name, subtitle, promo text, description, keywords)
- What's New text
- App Review Information note
- Marketing/support/privacy URLs
- Screenshot caption plan
- Public launch copy for website/social/email

## Ownership and Source of Truth

- Canonical app listing language: `PUBLIC_RELEASE_COPY.md`
- Canonical launch sequence: `PUBLIC_RELEASE_RUNBOOK.md`
- Canonical screenshot plan: `SCREENSHOTS.md`

When fields drift between files, update the canonical files in the hierarchy above, then sync supporting docs.
