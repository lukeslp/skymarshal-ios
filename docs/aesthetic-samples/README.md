# Aesthetic HTML samples

Static HTML mockups for the three 2026-05-15 directions. Open **`index.html`** in a browser, or open each file directly.

| File | Direction |
|------|-----------|
| `brutalist.html` | A — CRT / radar console (phosphor, Plex Mono) |
| `paper.html` | B — Paper zine (Fraunces + Plex, ribbon accent) |
| `cinematic.html` | C — OLED / gradient (Outfit display, system sans elsewhere, glass panels) |

Fonts load from Google Fonts when online. `backdrop-filter` in `cinematic.html` needs a Chromium/WebKit build that supports it.
