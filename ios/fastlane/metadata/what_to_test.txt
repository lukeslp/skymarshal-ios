Build 52 — ghost likes.

A ghost like is a like on a post whose author deleted their account, got suspended, or took the post down. Bluesky's feed never returns those, so until now nothing could show them to you and nothing could delete them.

What to try:
1. Content tab, filter to Likes, and run a full archive load. Let it finish — the ghost check only runs after the normal like sweep completes.
2. Look for like rows that read "Liked post no longer available." Those are the ghosts. They have no post text and no engagement counts, which is deliberate: those numbers are unknown, not zero.
3. Select one and delete it. It should delete like any other record, with the same confirmation and rate-limit behavior.

Worth knowing: if your account has no ghost likes, you will see none, and that is a valid result. It looks identical to the feature failing quietly, so no ghosts is not proof it works.
